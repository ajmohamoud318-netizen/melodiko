# Melodikoo Promo Video

## Setup

```bash
cd melodikoo-video
npm install
npm start        # opens Remotion Studio to preview
npm run build    # renders to out/video.mp4
```

## Timeline (7 seconds, 30fps)

| Frames  | Action |
|---------|--------|
| 0–50    | Tiger walks in from the right |
| 50–80   | Tiger settles, idles |
| 80–130  | Tap cursor appears → yellow star pops |
| 130–160 | Tiger happy, tail wagging |
| 160–210 | Fade to white → Melodikoo logo draws letter by letter |
